# K-Pop Idol Survival Simulator

This is a **web-based simulator** for a male K-pop idol survival competition.  
Players manage a trainee, train skills, participate in challenges, and aim to debut in a K-pop group.

## Features
- 111 contestants including the player (20% foreign trainees)
- Hosts: IVE's Won Young & Cha Eun Woo
- Judges: G-Dragon (rap), EXO Kai (dance), EXO Baekhyun & Chen (vocal)
- Player can customize 10% of their stats: Singing, Dancing, Rapping, Visual
- Training, performance, challenges, and elimination rounds
- Voting system: 50% fan vote + 30% online + 20% live audience
- Dynamic narrative with friendship, rivalry, and stage critiques
- Player can debut in the final group depending on stats and choices
- Group size, company, and positions (main/lead/visual/center) determined by performance and votes

## How to Run
1. Clone or download this repository
2. Open `index.html` in your web browser (works on Android)
3. Start the game and follow the interactive choices
